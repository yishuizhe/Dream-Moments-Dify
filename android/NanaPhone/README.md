# 娜娜手机端

这是 Dream-Moments-Dify 的自研安卓执行端。它不包含第二个 AI，只接受电脑端签名后的结构化动作，
因此电量、型号和网络等结果来自安卓系统本身，不依赖模型决定是否调用工具。

## 安装与配对

1. 从项目的 GitHub Releases 下载并安装 `NanaPhone-debug.apk`；也可以按下文从源码自行构建。如系统阻止安装，请只为当前文件管理器临时允许“安装未知应用”。
2. 打开“娜娜手机端”，设置端口（默认 `8765`）并点击“启动 / 重启手机服务”。
3. 若要点击、输入、滑动或返回，点击“打开无障碍权限设置”，只开启“娜娜手机控制”。
4. 复制 App 显示的配对密钥。
5. 打开 Dream 控制台 `http://127.0.0.1:8501/console`，在“娜娜自研手机端”填写：
   - 地址：同一局域网可用手机局域网 IP；异地建议用 `http://手机Tailscale地址:8765`；
   - 配对密钥：粘贴 App 中的密钥；
   - 启用自研手机端：打开。
6. 保存配置并重启机器人。

授权微信发送者、授权会话、群聊开关和高风险确认仍沿用“Operit 手机控制”区域中的安全设置；
启用自研手机端后，实际任务不会再发送给 Operit。

## 已支持动作

- 实时读取电量、充电状态和电池温度；
- 读取品牌、型号、安卓版本；
- 读取网络连接和存储空间；
- 读取当前应用、可见文字、控件 ID、屏幕位置和可操作状态；
- 按应用名称或包名打开应用；
- 打开系统设置和电池设置；
- 返回、主页、最近任务、通知栏；
- 按可见文字点击、向当前输入框输入、上下滑动。

服务仅接受带时间戳、随机 nonce 和 HMAC-SHA256 签名的请求；签名超过两分钟或 nonce 重复会被拒绝。
建议仅通过局域网或 Tailscale 使用，不要在路由器上做公网端口映射。

## 本地构建

项目使用 Java 17、Android SDK 35 和 AGP 8.9.2。根目录的 `.android-tools` 是隔离构建环境，不需要系统安装 Android Studio。

```powershell
powershell -ExecutionPolicy Bypass -File android/NanaPhone/build_apk.ps1
```
