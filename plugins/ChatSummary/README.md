# ChatSummary

Dream 内置群聊总结 / 成员锐评插件（本地历史）。

记录来自本机 SQLite：`data/database/chat_history.db`。  
总结结果会额外保存到：`data/summaries/<群名>/`。

## 群总结（不限当天）
- `总结`
- `总结群聊`
- `总结最近50条`
- `总结群聊100条`
- `总结最近200条`（最多 300 条）
- `总结最近3天`
- `总结7天`

## 仅总结今天
- `总结今日`
- `总结今天群聊`
- `娜娜，总结今日群聊`

## 成员总结 / 客观锐评
- `总结@某成员`
- `总结 某成员`
- `娜娜总结@某成员`
- `娜娜，总结某成员`
- `评价@某成员`
- `锐评 某成员 50条`

说明：
- 默认近 100 条本地记录，可写 10~300 条
- “最近N天”按本地历史时间过滤，不是只能看当天
- 成员名按群里显示昵称匹配
- 锐评要求客观真实，不讨好
