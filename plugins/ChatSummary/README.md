# ChatSummary

Dream 内置群聊总结 / 成员锐评插件（本地历史）。

记录来自本机 SQLite：`data/database/chat_history.db`。  
总结结果会额外保存到：`data/summaries/<群名>/`。

## 群总结（不限当天）
- `总结`
- `总结群聊`
- `总结最近50条`
- `总结群聊100条`
- `总结最近200条`（最多 300 条）
- `总结最近3天`
- `总结7天`

## 仅总结今天
- `总结今日`
- `总结今天群聊`
- `娜娜，总结今日群聊`

## 成员总结 / 客观锐评
- `总结@张三`
- `总结 张三`
- `娜娜总结@张三`
- `娜娜，总结张三`
- `评价@张三`
- `锐评 张三 50条`

说明：
- 默认近 100 条本地记录，可写 10~300 条
- “最近N天”按本地历史时间过滤，不是只能看当天
- 成员名按群里显示昵称匹配
- 锐评要求客观真实，不讨好
- 按稳定群 ID 读取历史，成员名优先从当前群通讯录解析；同名歧义会提示确认，不猜测。
- 拍一拍等系统事件和历史生成的总结不作为真人证据；使用当前机器人的真实昵称。
- 对全体成员逐个评价或排行的请求交由本群对话处理器按实际发言样本回答，不把整句误当作单个成员名。
